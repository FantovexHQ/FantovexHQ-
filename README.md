# Fantovex Esports Website

A lightweight static website for Fantovex Esports.

## Files

- `index.html` — homepage
- `contact.html` — contact/community page
- `assets/style.css` — all styling
- `assets/app.js` — mobile menu + subtle reveal animations
- `assets/logo.svg` — lightweight Fantovex-style logo

## GitHub Pages

1. Create/open a GitHub repository.
2. Upload **all files and folders** from this ZIP.
3. Make sure `index.html` is in the repository root.
4. Open **Settings → Pages**.
5. Under deployment, select **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save and wait for GitHub Pages to publish.

All internal links are relative, so the site works on GitHub Pages without changing paths.
